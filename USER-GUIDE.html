What is WaveDeck?

WaveDeck is a lightweight, portable internet-radio player for Linux, Windows, and macOS. It organizes streaming stations into searchable groups and subgroups, lets you build personal Presets and Favorites, remembers your listening history and station-volume adjustments, and can carry the same library and preferences between computers on a USB stick.

1. Quick Start

Extract the complete package to a normal folder or USB stick, then launch the version made for your computer. Click a station to play it, use the volume control beneath the artwork, and use the toolbar to show Search, Presets, Favorites, or Your Top Five. WaveDeck creates a Data folder beside the application and leaves existing files in it alone.

Linux

Double-click WaveDeck.AppImage. If it will not start, open its Properties, choose Permissions, and enable “Allow executing file as program.” Linux requires mpv to be installed. Sidebar Mode is designed for Linux Mint Cinnamon on X11.

Windows

Double-click WaveDeck.exe. WaveDeck is portable and does not install itself. If SmartScreen appears, choose More info, verify that the application is WaveDeck, and choose Run anyway. Sidebar Mode and its Notepad are available from the toolbar.

macOS

Extract the ZIP on the Mac itself. In Terminal, type xattr -dr com.apple.quarantine , drag WaveDeck.app into Terminal, and press Return. Then Control-click the app, choose Open, and confirm.

2. Portable Data and Updates

WaveDeck keeps your information in a folder named Data beside the application. If the Windows EXE, Linux AppImage, and macOS app are placed in the same WaveDeck Portable folder, they can all use that same data.

Updating WaveDeck: Close the application and replace only the executable or app. Do not delete or replace the Data folder.

WaveDeck creates missing files for a new user, but it does not overwrite an existing library, preferences, listening history, notes, or backups during startup.

FileWhat it contains
library.jsonStations, groups, subgroups, ordering, and station assignments.
preferences.jsonPersonal choices such as Favorites, Presets, station gain, update preference, and interface settings.
listening-history.jsonQualified listening time used by Your Top Five.
Other Data filesPortable notes, backups, and supporting state created as needed.

3. Playing Stations

Click a station name to start its live stream. Clicking the selected station also opens its details, including country, description, best-effort bitrate information, and its Station Gain control. Use the square Stop button to stop playback, the speaker button to mute, and the slider to change overall volume.

Station Gain

Some streams arrive naturally louder or quieter than others. The Station Gain slider adjusts only the selected station from −12 dB to +12 dB in 0.5 dB steps. You can move it while listening and hear the result immediately. WaveDeck remembers the setting for that station and applies it automatically next time. Reset returns it to 0 dB.

Listening History

Listening time begins counting after 30 seconds of continuous playback. A station can appear in Your Top Five after accumulating at least five minutes. Settings shows each station’s total and includes a Reset Listening History button.

4. Toolbar and Station Lists

The fixed toolbar sits directly beneath the player controls. From left to right:

ControlWhat it does
SearchShows or hides Search. It matches names, groups, subgroups, countries, descriptions, and stream URLs. While text is present, Presets and Your Top Five temporarily disappear so only results are shown.
PresetsShows or hides your ordered Presets list. Presets begins visible on each launch.
FavoritesFilters the main Stations listing to Favorites only. Click again to restore every station.
Your Top FiveShows or hides your five most-listened stations. It begins hidden on each launch.
NotepadOpens the auto-saving notepad while Sidebar Mode is active. Notepad is available on Linux and Windows but not on macOS.
Sidebar ModeDocks WaveDeck against the right edge of the desktop on Linux Mint Cinnamon or Windows. Sidebar Mode is not available on macOS.
SettingsOpens station management, groups, importing and exporting, platform controls, About, and the changelog.

Groups and subgroups start collapsed. Use Expand All and Collapse All beside Stations when you want to open or close the complete hierarchy.

5. Station Shortcuts and Markers

ActionResult
Click a stationPlay it and show its details.
Click its starAdd or remove it from Favorites.
Ctrl + clickAdd or remove it from Presets.
Ctrl + Shift + clickToggle its pre-roll advertisement warning.
Shift + clickOpen that station for editing in Settings.

The star’s shape shows Favorite status: filled means Favorite. Its color shows station status: lime green means Preset, gold means ordinary, and dark orange-red warns of pre-roll advertising. The warning color takes priority.

Preset Order

Drag the handle beside a Preset to reorder it. The order is saved and is also used by the Next and Previous media keys.

6. Settings and Library Management

Stations

Add, edit, delete, search, and filter stations. Each station can have a name, URL, group, optional subgroup, country, description, Favorite status, Preset status, and pre-roll warning. Only the user can delete a local station.

Groups and Subgroups

Create, rename, reorder, and remove the categories used to organize the player. Subgroups are optional and always belong to a main group.

Import and Export

Export Library creates WaveDeck_Library.json containing stations, groups, subgroups, ordering, assignments, and an automatic update timestamp. It does not include personal Favorites, Presets, station gain, notes, or listening history.

Import offers two choices:

  • Add New from Library adds new listings without disturbing existing stations or personal preferences.
  • Replace Library removes the current station library after confirmation and imports the selected library fresh. Personal preferences remain separate.

Automatic Station Updates

When Download new stations is enabled, WaveDeck quietly checks the master library at startup. A newer master can add stations, groups, and subgroups and correct station URLs, countries, and descriptions. It never deletes a station, restores one you deleted, or changes Favorites and Presets. If the update site is unavailable or its file is invalid, WaveDeck simply continues with the local library.

7. Sidebar Mode and Platform Features

Sidebar Mode

On Linux Mint Cinnamon with an X11 session or on Windows, move WaveDeck to the desired screen and click the Sidebar Mode button. WaveDeck docks against that screen’s right edge and reserves the space so ordinary maximized windows use the remaining desktop area. Click it again to return to the previous floating window and position.

Settings can make WaveDeck enter Sidebar Mode automatically at startup. If the operating system cannot complete the docking operation, WaveDeck remains in normal mode and displays the reason beneath the artwork. Sidebar Mode is not available on macOS.

Sidebar Notepad

The notepad button appears only while Sidebar Mode is active on Linux or Windows. It opens a plain-text writing area at the bottom of the sidebar, saves automatically in Data, and starts collapsed at every launch.

Linux Applications Menu and Panel Shortcut

The Panel Shortcut tab can add, update, or remove WaveDeck’s managed Linux Applications-menu entry. Because releases use the stable filename WaveDeck.AppImage, replacing the file in place keeps an existing launcher pointed at the correct location.

8. Keyboard Media Keys

  • Play/Pause: stops the live stream; press again to reconnect to the same station at the current live point. With no station selected, Play starts the first Preset.
  • Next/Previous: moves through the ordered Presets list and wraps at either end.
  • Stop: stops playback where supported.

WaveDeck periodically retries media-key registration. Another program may temporarily own a global media key. Returning focus to WaveDeck or selecting a station gives it another opportunity to reclaim control. macOS may request Accessibility permission for global media keys; mouse controls work without it.

9. Troubleshooting

The Linux AppImage will not open

Open Properties → Permissions and enable “Allow executing file as program.” Also confirm that mpv is installed. WaveDeck keeps Linux runtime locks and playback sockets on the local computer so common FAT and exFAT USB sticks can be used.

Windows displays SmartScreen

Choose More info, confirm the application is WaveDeck, and choose Run anyway. The portable build is not installed into Windows.

macOS says the app cannot be opened

Make sure the ZIP was extracted on the Mac. Run the quarantine-removal command shown in Quick Start, then Control-click the app and choose Open. If necessary, use System Settings → Privacy & Security → Open Anyway. The current package requires macOS 14 or newer on Apple Silicon, or macOS 11 or newer on Intel.

A station will not play

The station may be offline or may have changed its stream address. Try another station to verify playback. If only one fails, edit its URL or leave automatic station updates enabled so a published correction can be received.

Protecting your collection

Back up the entire Data folder periodically. When updating WaveDeck, replace only the application—not Data.
