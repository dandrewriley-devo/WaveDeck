WAVEDECK FOR macOS — FIRST LAUNCH
Version 0.4.3 universal test build

REQUIREMENTS

- macOS 14 Sonoma or newer
- An Intel or Apple Silicon Mac
- An internet connection for radio streams

WHAT IS IN THE ZIP

- WaveDeck.app
- This instruction file

WaveDeck is not signed with a paid Apple Developer certificate. The app is
ad-hoc signed so macOS can verify that its bundle is internally consistent,
but Apple may still block the first launch because it cannot identify a paid
developer.

PUTTING WAVEDECK ON THE USB STICK

1. Place the ZIP in your WaveDeck Portable folder on the USB stick.
2. Open the ZIP on the Mac so macOS extracts WaveDeck.app and this file beside
   the existing Data folder.
3. Do not place WaveDeck.app inside Data.

The portable folder should look like this:

  WaveDeck Portable/
    Data/
    WaveDeck.app
    WaveDeck.exe
    WaveDeck.AppImage

Only the files you have added will be present. The three applications all use
the same Data folder. WaveDeck creates missing data files but never replaces
existing library, preference, listening-history, note, or backup files during
startup.

FIRST LAUNCH

Before opening WaveDeck for the first time:

1. Open Terminal from Applications > Utilities.
2. Type the following command, including the space at the end, but do not press
   Return yet:

     xattr -dr com.apple.quarantine 

3. Drag WaveDeck.app from the USB stick into the Terminal window. Terminal will
   add its complete path after the command.
4. Press Return.
5. Control-click WaveDeck.app, choose Open, and confirm Open if macOS asks.

If macOS still blocks it, open System Settings > Privacy & Security, scroll to
the Security section, and choose Open Anyway for WaveDeck. This approval should
only be necessary once for this copy of the app.

MEDIA KEYS

WaveDeck attempts to use Play/Pause, Next, Previous, and Stop media keys. macOS
may ask for permission to control the keyboard. If the keys do not work, check
System Settings > Privacy & Security > Accessibility and allow WaveDeck. Normal
mouse controls work without this permission.

PORTABLE DATA

Keep WaveDeck.app beside Data. If the app is moved somewhere else, it will use
or create a Data folder beside its new location. Electron's temporary runtime
files stay under the current Mac user's Library folder rather than on the USB
stick, which avoids removable-drive locking problems.

UPDATING OR REMOVING

To update WaveDeck later, close it and replace only WaveDeck.app. Leave Data
untouched. To remove only the Mac application, delete WaveDeck.app; your shared
Data folder and the Windows and Linux applications will remain.

Sidebar Mode is intentionally available only in the Linux version.
