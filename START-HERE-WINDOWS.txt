WAVEDECK PORTABLE FOR WINDOWS
Version 0.6.5 (64-bit Intel/AMD)

QUICK START

1. Unzip the whole package to a normal folder or thumb drive.
2. Double-click WaveDeck.exe.
3. If Windows SmartScreen appears, choose More info, confirm that the app is
   WaveDeck, then choose Run anyway.

WaveDeck is portable. It does not install itself or write an uninstaller.

On a completely new installation, WaveDeck creates its library with 360
stations and adds seven varied stations to Presets as a useful starting point.
Existing Data files are never replaced during startup.

PORTABLE DATA

WaveDeck creates a folder named Data beside WaveDeck.exe on first launch. The
shareable station library is stored in library.json; personal Favorites and
Presets are stored separately in preferences.json. Listening history and
backups also remain under Data. Electron's temporary runtime files stay on the
Windows computer so the app can run from ordinary USB filesystems.

The Linux AppImage and Windows EXE can sit beside the same Data folder on a USB
stick. Whichever version you launch will use the same library and preferences,
while each operating system keeps its temporary runtime files on that computer.

To update later, close WaveDeck and replace only WaveDeck.exe. Leave Data
untouched.

KEYBOARD MEDIA KEYS

While WaveDeck is running, it registers the standard media keys directly with
Windows:

  - Play/Pause stops the live stream; press again to reconnect at the live point.
  - Next and Previous move through your custom Presets order and wrap around.
  - Stop stops playback.

WaveDeck retries any unavailable media-key registrations every 15 seconds and
whenever its window receives focus. Windows grants a global key to one app at a
time, so another program that already owns a key can temporarily prevent
WaveDeck from registering it.

LIBRARY IMPORT AND EXPORT

Export Library creates WaveDeck_Library.json containing stations, groups,
subgroups, their order, station assignments, and an automatic update timestamp.
It never includes Favorites or Presets.
Import can add only new listings or replace the entire library after a strong
confirmation; either choice preserves the user's personal preferences.

AUTOMATIC STATION UPDATES

WaveDeck quietly checks for a newer master station library when it starts. The
check can add stations, groups, and subgroups and correct existing stream URLs,
countries, and descriptions. It never deletes a local station, restores a
station you deleted, or changes Favorites and Presets. If the update site is
unavailable or its file is invalid, WaveDeck continues using the local library
without displaying an error. Use Download new stations on the Settings Stations
tab to disable or re-enable the check; WaveDeck remembers the choice.

SEARCH, PRESETS, FAVORITES, AND YOUR TOP FIVE

The magnifying-glass button shows or hides station search, which begins hidden
on each fresh launch. Search matches station names, groups, subgroups, countries,
descriptions, and stream URLs. While a search is active, Presets and Your Top
Five temporarily disappear so only matching stations remain. The bookmark
button shows or hides Presets; Presets is visible on each fresh launch. The star
button filters the main station list to Favorites only. The clock-and-list
button shows or hides the five-station Your Top Five section, which begins
hidden on each fresh launch.

STATION GAIN

Click a playing station to open its details. Station Gain adjusts only that
station from -12 dB to +12 dB while it plays. WaveDeck remembers the adjustment
in preferences.json and automatically applies it the next time that station
plays. Station Gain is never included in a library export or update.

STATION SHORTCUTS

  - Click a station: play it and show its details.
  - Click its star: toggle Favorite status.
  - Ctrl-click: toggle Preset status.
  - Ctrl+Shift-click: toggle the pre-roll warning.
  - Shift-click: edit the station in Settings.

SIDEBAR MODE AND NOTEPAD

The Sidebar button docks WaveDeck against the right side of the current monitor
and reserves that part of the Windows desktop. Maximized windows use the space
beside it. Click the button again to restore WaveDeck's previous floating size
and position. Settings > Sidebar can make WaveDeck enter Sidebar Mode each time
it starts.

The Notepad button appears while Sidebar Mode is active. It opens a collapsible,
automatically saved plain-text notepad. Notes remain in the shared Data folder.

Linux Applications-menu and panel-shortcut management is not available on
Windows.

Playback is provided by the bundled mpv engine; no separate player is needed.
